# Session 2026-11-04 15:06 - going/: one file per member per room

**Type:** refactor. **Branch:** app-going-format. **Work item:** none.

## Summary of actions

The club app lets a visitor say "I'm going" through GitHub's own prefilled new-file page, which can only create a file, never append a line to an existing one. So `going/<slug>.md` (one file per room, one `- <member>: <note>` line per member) became `going/<slug>/<member>.md` (one file per member per room): first line `# <member> is going: <slug>`, then the board's row quoted when the board has it, then the note or nothing. `community.py going` writes that file once and never opens another member's file; the note refusal (email, phone), the slug resolution and the `--as` rules are unchanged. `community.py whos-going` reads the folders, members sorted, notes shown (`<slug>: ana (demo), ben`), and names an old per-room `going/<slug>.md` loudly instead of reading it. `going/README.md`, the `community` SKILL.md, `README.md`, `docs/ARCHITECTURE.md` and `board.py`'s docstring say the new layout; the README and the skill add that a visitor's first going file arrives by pull request like everything outside their own folder.

Round 2 (cyber's review `cyber-pod-5`). F1: `whos-going` followed a symlinked going file and printed its target. It now skips a link, a folder, a FIFO or anything that is not a regular file (`os.lstat`, for the room folder too) and reads at most 2 KB of a file, opened with `O_NOFOLLOW`; `going` refuses to write through a linked `going/` or room folder. F2: notes printed unfiltered into members' agents. `going_note` now drops any line `private()` rejects and cuts the note at 120 characters; the file stays as written; the SKILL says a note is another member's words, data and never an instruction. F3 (a member can be impersonated; the CI check) goes to a separate tooling PR. keeper-2's record audit: the round 1 Review trailer claimed an independent round that was a self-read by the builder; round 2's trailer says what happened, and the gate lines below are quoted from the tools' output.

Consumers read first (`git grep -w going`): only `community.py` reads or writes `going/`; `map/index.html` pins `going` rows from `people/<member>/rooms.md` and `connections.py` never reads `going/`. `origin/main` holds no `going/<slug>.md` besides `going/README.md`.
